**unRaid Security Center Plugin**

Dostarcza serwerowe skrypty pomocnicze dla systemu monitorowania unRaid Security Center (USC) -
m.in. zrzut telemetrii SMART (ATA + NVMe) wykorzystywany przez kolektor USC uruchomiony
na osobnym hoście (OMV). Sam plugin nie ma własnego interfejsu WebGUI - działa jako
bezpieczny, tylko-do-odczytu punkt wejścia wywoływany przez ograniczony klucz SSH.
